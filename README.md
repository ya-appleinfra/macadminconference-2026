## Think Declarative

Презентация для Sysadmin 2026 о переходе от
императивного MDM к Declarative Device Management (DDM).

В презентации разобраны ограничения классического MDM и то, как DDM
помогает описывать желаемое состояние устройства, применять настройки
по условиям и получать сведения об их фактическом состоянии.
